# Mystic Name Cipher

A small static web app that generates a "mystic" secret code, secret number, secret name, and lucky number from two names.

## Features

- Enter two names
- Generate a secret code using ASCII-based logic
- Generate a unique 4-digit secret number
- Generate a merged secret name
- Calculate a lucky number from the combined character sum
- Simple, responsive dark-themed UI

## Project Structure

- `index.html` — main app and styling
- `README.md` — project documentation

## How to Run

Open `index.html` in a browser.

You can also serve it locally with any static file server, for example:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
